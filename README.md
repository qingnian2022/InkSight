# md-rust

本地优先的 Markdown 编辑器。选一个文件夹当知识库，直接读写磁盘上的 `.md` 文件——没有私有数据库，随时可以用 Git、其他编辑器或云盘接管。

当前为 **MVP**：左目录树 + 已打开文件标签 + 编辑区。编辑区用 Milkdown Crepe 做块级实时编辑——输入 `#` 直接变标题，`/` 唤起插入菜单，全程不见 Markdown 标记。

源码模式（CodeMirror 6 + Live Preview）的代码仍保留在仓库里（`state.editorMode === "source"`），但默认不启用，界面上也没有切换入口；需要时改 `store.ts` 里的初值即可。

## 运行

```bash
npm install        # npm 安装（本机 pnpm 的符号链接异常，暂用 npm）
npm run tauri dev  # 桌面端
npm run dev        # 只跑前端（浏览器里没有 Tauri IPC，无法读写文件）
```

构建：`npm run tauri build`。

## 已实现

| 能力 | 说明 |
|---|---|
| 打开知识库 | 选择任意文件夹，递归扫描 `.md / .markdown / .mdx` |
| 目录树 | 展开折叠、目录优先排序、新建文档、刷新 |
| 标签行 | 多文档同时打开，未保存圆点，Ctrl+W 关闭；右侧是「阅读/编辑」、大纲、主题开关 |
| 打开即渲染 | 默认阅读态，整篇按结果渲染；点正文或 Ctrl+E 进入编辑 |
| Live Preview | 编辑时**光标所在行显示原始标记**，光标一离开就渲染：标题、列表、任务列表、引用、分割线、行内强调、链接、**表格**、**代码块**（卡片式：语言标签 + 边框圆角 + 语法高亮） |
| 保真 | 源码就是文档本身，保存**一个字节都不改**（`*` 仍是 `*`、表格对齐原样、空行不压缩） |
| 工具栏 | md-editor-v3 风格：左侧段落样式下拉 + 三组图标（行内格式 / 块级格式 / 插入），右侧撤销重做；24px 线性图标、悬停高亮、分割线分组 |
| 保存 | 标题栏「自动保存」开关（默认开：停顿 0.8s 写盘；关：仅 Ctrl+S / 状态栏 / 右键手动写盘），状态栏四态（已保存/未保存/保存中/失败） |
| 新建文档 | 新建只开内存中的「未命名」标签，磁盘不创建文件；Ctrl+S / 状态栏 / 右键保存时弹框确认名称与目录（默认当前文档所在文件夹，无打开文档则知识库根目录），确认后才落盘 |
| 大纲 | 从标题实时提取，点击滚动到对应标题 |
| 主题 | 浅色 / 深色，记忆在 localStorage |
| 删除 | 移到 `<vault>/.trash/`，不硬删 |
| 正文列宽 | 工具栏右侧「列宽」选择器：窄 60% / 标准 75% / 宽 90% / 全宽，按编辑区宽度百分比计算（下限 560px）；两套内核共用 `--ed-max` 变量，记忆在 localStorage |
| 目录树右键 | 文件：新建（所在文件夹）/ 复制副本 / 重命名 F2 / 复制路径 / 删除 Del；文件夹：新建文档 / 新建子文件夹 / 复制文件夹 / 重命名 / 复制路径 / 删除；空白区域：根目录新建与刷新。重命名、新建用统一命名弹窗（Enter 确认 / Esc 取消） |
| 右键菜单 | 自定义：编辑器内是编辑动作（撤销/剪切/粘贴/加粗…），其余区域是应用动作；WebView 默认菜单已禁用 |
| 块级编辑 | Milkdown Crepe：顶部工具栏、`/` 命令、块手柄、表格、公式；按需加载，不拖慢首屏 |
| 界面 | 侧栏 / 标签栏 / 状态栏统一 46px 行高与 14px 圆角；Crepe 顶栏、`/` 插入菜单、气泡工具栏、代码块文案全部中文化；空状态、大纲抽屉、滚动条与深浅色一并整理 |

## 注意

- **源码模式默认未启用**：现在固定走富文本。Live Preview 那套代码还在，改 `store.ts` 里 `editorMode` 的初值就能切回去——它的光标行会显示 `#`、`**`，这是该形态的固有表现。
- **保存会重排**：Milkdown 的序列化器会统一 `*`→`-`、表格补空格对齐、列表缩进、合并连续空行。动过字之后 `git diff` 会出现格式噪音——这是结构化编辑器的固有代价，不是 bug。
- **本地图片暂显示为占位 chip**（`🖼 文件名`）：`assets/` 下的相对路径需要自定义协议才能被 WebView 读取，尚未实现；`http(s)` 图片正常显示。（富文本模式同样读不到本地图片。）
- 表格渲染是整块 widget：光标进入表格任意一行会切回源码，可直接编辑。
- 代码块（富文本模式）是卡片式：顶栏左边是语言名、右边是「复制」，代码区带行号，四周 1px 边框、9px 圆角。语法高亮走项目自己的 `--syn-*` 低饱和色板（关键字墨绿、字符串赭石、数字砖红、注释灰斜体），深浅色自动跟随；Crepe 自带的折叠箭头已隐藏。
- `src-tauri/tauri.conf.json` 的 `csp` 仍为 `null`，正式版前需收紧。
- 本机 `pnpm install` 会生成空 `@scope` 目录导致 Vite 找不到依赖，暂用 `npm install`。
- 未提交 git（按当前约定）。
