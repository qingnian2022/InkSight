# md-rust

本地优先的 Markdown 编辑器。选一个文件夹当知识库，直接读写磁盘上的 `.md` 文件——没有私有数据库，随时可以用 Git、其他编辑器或云盘接管。

当前为 **MVP**：左目录树 + 已打开文件标签 + Live Preview 编辑区（CodeMirror 6，编辑后即渲染）。

## 运行

```bash
npm install        # npm 安装（本机 pnpm 的符号链接异常，暂用 npm）
npm run tauri dev  # 桌面端
npm run dev        # 只跑前端（浏览器里没有 Tauri IPC，无法读写文件）
```

构建：`npm run tauri build`。

## 已实现

| 能力 | 说明 |
|---|---|
| 打开知识库 | 选择任意文件夹，递归扫描 `.md / .markdown / .mdx` |
| 目录树 | 展开折叠、目录优先排序、新建文档、刷新 |
| 标签行 | 多文档同时打开，未保存圆点，Ctrl+W 关闭；右侧是「阅读/编辑」、大纲、主题开关 |
| 打开即渲染 | 默认阅读态，整篇按结果渲染；点正文或 Ctrl+E 进入编辑 |
| Live Preview | 编辑时**光标所在行显示原始标记**，光标一离开就渲染：标题、列表、任务列表、引用、分割线、行内强调、链接、**表格**、**代码块**（围栏隐藏 + 语言标签） |
| 保真 | 源码就是文档本身，保存**一个字节都不改**（`*` 仍是 `*`、表格对齐原样、空行不压缩） |
| 工具栏 | 语雀式：段落样式下拉（正文/标题/引用/代码块）+ 加粗斜体删除线行内码链接 + 列表/引用/代码块/分割线 + 图片 + 撤销重做 |
| 保存 | 800ms 防抖 + Ctrl+S；状态栏四态（已保存/未保存/保存中/失败） |
| 大纲 | 从标题实时提取，点击滚动到对应标题 |
| 主题 | 浅色 / 深色，记忆在 localStorage |
| 删除 | 移到 `<vault>/.trash/`，不硬删 |

## 注意

- **编辑时当前行会显示 `#`、`**`**：这是 Live Preview 的固有形态（Typora 同理），光标离开即渲染。要"编辑时也完全零标记"只能换成结构化编辑器，代价是保存会重排文件。
- **本地图片暂显示为占位 chip**（`🖼 文件名`）：`assets/` 下的相对路径需要自定义协议才能被 WebView 读取，尚未实现；`http(s)` 图片正常显示。
- 表格渲染是整块 widget：光标进入表格任意一行会切回源码，可直接编辑。
- 代码块只做背景 + 围栏隐藏 + 语言标签，**没有语法高亮**。
- `src-tauri/tauri.conf.json` 的 `csp` 仍为 `null`，正式版前需收紧。
- 本机 `pnpm install` 会生成空 `@scope` 目录导致 Vite 找不到依赖，暂用 `npm install`。
- 未提交 git（按当前约定）。
