1导入流程

  • 右键目录树中的文件夹 → 「导入 Markdown…」或「导入文件夹…」
  • 文件模式：多选 .md / .markdown / .mdx；文件夹模式：可多选文件夹
  • 复制到右键的那个文件夹，原文件不动
  • 文件夹整棵复制（含图片），保留结构；重名自动「xx (2)」
api.ts · importDocs()lib.rs · import_docs

2导出流程

  • 单篇：文件右键「导出此文档 (.md)」
  • 文件夹：右键「导出此文件夹」→ zip 保留结构
  • 整库：空白处「导出整库 (zip)」，排除 .trash
  • 文件名默认 md-rust-backup-YYYYMMDD.zip
lib.rs · export_zip新增依赖 zip = "2"

3数据目录与风险

  • 主路径：<exe 目录>\data，启动自动创建
  • 装进 Program Files 不可写 → 自动降级 AppData 并在状态栏提示
  • 推荐便携版（zip 解压即用），彻底避开权限问题
  • 老用户首次启动提示「是否复制现有知识库到 data」
data_dir 命令BaseDirectory::Executable
