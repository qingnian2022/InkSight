1实现方式

  • Tauri 2 原生托盘：开 tray-icon + image-png feature
  • 拦截 CloseRequested → hide()，进程驻留
  • 托盘图标复用现有 icons/icon.ico，无需新资源
  • 纯 Rust 侧实现，前端零权限新增；「新建文档」走 emit 事件，前端 3 行

2推荐同批加上

  • 单实例锁（tauri-plugin-single-instance）：托盘常驻后二次启动唤醒已有窗口，避免多开（托盘场景下几乎必配）
  • 设置项「关闭时退出程序」（默认关）：尊重想点 ✕ 就真退出的用户
  • 托盘 tooltip：md-rust — 我的知识库

3边界处理

  • 文档实时落盘，隐藏期间自动保存照常，无丢失风险
  • 首次最小化弹一次气泡说明「右键托盘可退出」，之后静默
  • dev 热重载时托盘短暂消失属正常，release 无此问题
  • Windows 关机正常结束进程，md 已在磁盘
