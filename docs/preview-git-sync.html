1同步策略

  • 启动时：静默 pull --rebase --autostash
  • 保存写盘后 30s：有改动才 commit + push
  • 每 15 分钟：双向对齐（可关，存 localStorage）
  • 无网络静默跳过，本地提交保留、联网补推
lib.rs · sync_now调用系统 git

2冲突处理

  • markdown 纯文本，git 自动合并大部分改动
  • 同段冲突 → rebase 暂停，状态栏红字提示
  • 绝不自动覆盖，建议先「导出整库」再手动处理
  • 提交文案固定 sync: HH:mm，不污染历史
