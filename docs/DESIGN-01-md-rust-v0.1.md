## 1. 视觉主题

### 1.1 路线

| 项 | 决策 | 理由 |
|---|---|---|
| 分支 | `product` | 交付物是可操作的编辑工作区，不是品牌物料 |
| 产品模式 | Devtool / editor 为主，Editorial / knowledge 为辅 | 面板化、键盘优先、可调分栏是主行为；阅读节奏只作用于正文列 |
| 主视觉谱系 | 「纸与墨」：暖中性纸面 + 近乎黑的结构色 + 单一矿物青强调 | 写作工具的默认状态应安静；强调色只在当前位置、焦点与链接出现 |
| 辅助谱系 | 无 | 任何第二个风格来源都会与「正文唯一主角」冲突 |
| 不复制 | 语雀的紫色体系与卡片嵌套、Notion 的灰底块、Typora 的纯白无框、Obsidian 的深色紫 | 这些是被参考的交互范式，不是被复用的视觉皮肤 |

### 1.2 五条视觉原则

1. **一屏一个主角**：正文列是唯一的视觉重心，其余区域靠色差退后，不靠加框抢注意力。
2. **边界只用一次**：能用底色区分就不加边框；能用 1px 线就不加阴影。
3. **密度分层**：树行与控件 30px、状态栏 24px、标签行 42px、工具栏 42px、正文 16px/1.8；压缩只发生在非阅读区。
4. **强调色稀缺**：全屏同时出现的青色面积不超过 5%，只标记「你在哪」与「可以点」。
5. **渲染不改内容**：所有即时渲染都是视图层装饰，关闭后必须逐字还原。

### 1.3 五条交互原则

1. 键盘可达一切重复操作：Ctrl+P 打开、Ctrl+Shift+F 搜索、Ctrl+S 保存、Ctrl+\ 折叠。
2. 保存状态常驻状态栏，四态可见，任何一次保存失败都有就地重试。
3. 破坏性操作先移到 `.trash/`，并说明影响对象。
4. 中文输入法组合期间，不重建装饰、不触发搜索与校验。
5. 外部改动（其他编辑器、Git）必须被监听，并给出「加载磁盘版本 / 保留我的」的显式选择，不静默覆盖。

### 1.4 事实、假设与约束

- **事实**：现有仓库为 Tauri 2 + Vue 3 模板，无任何设计 token 或主题文件；窗口 800×600、CSP 为 null。
- **假设**：单用户、单窗口为主，日使用时长 1 小时以上，中文长文写作占多数。
- **约束**：离线可运行，不加载外部字体或 CDN；P0 不做表格渲染与图片内联。

### 3.3 换行与截断

| 场景 | 规则 |
|---|---|
| 文档 H1 | 允许换行，最多 3 行；再长在标题区纵向滚动，不缩字号 |
| 树行标题 | 单行截断 + `title` 提示；缩进不因长度改变 |
| 面包屑 | 中间层级可截断，末级永远可见 |
| 正文段落 | 自然换行，不做两端对齐；中文标点按 `clreq` 挤压由浏览器处理 |
| 正文内的长 URL / 代码 | `overflow-wrap: anywhere`，不撑破测量宽度 |
| 状态栏 | 不换行，右侧信息优先级高于左侧 |

| 链接 | `--accent`，下划线为强调色 32% 透明；悬停变实线 |
| 活动行 | 底 `--row-active`，左右各外扩 16px；原始标记 `--text-tertiary` + 等宽；光标 1.5px `--accent` |

活动行规则是 Typora 式渲染的核心：**只有包含选区的行显示 `#`、`**`、`-` 等标记，其余行全部隐藏**。离开该行即恢复隐藏，输入法组合期间不刷新装饰。

| 区域 | 尺寸 | 滚动归属 | 说明 |
|---|---|---|---|
| 外壳留白 | 10px 内边距 + 10px 间距 | — | 窗口底为 `--canvas`，两张圆角卡片浮在其上 |

| 编辑画布 | 自适应，最小 480px | `.canvas` 自身滚动 | 白底，正文列居中，无文档头（文件名已在标签上） |
| 状态栏 | 高 24px，跨两列 | 无 | 透明底，位于卡片之外，只放事实 |

### 5.2 正文测量与留白

- 正文列 `max-width: 720px`，`margin: 0 auto`，左右内边距 24px。
- 顶部 44px、底部 40vh 留白：保证最后一行可以滚到视口上半部（写作工具的必要行为）。
- 断点变化时只改外框，不改正文测量宽度。

### 5.3 空间压力与降级顺序

| 压力 | 处理 |
|---|---|
| 窗口 < 1080px | 工具栏先隐藏「插入」组，再隐藏块级组；永不换行、不缩按钮 |
| 窗口 < 860px | 左栏收起为抽屉，正文占满；标签行保留 |
| 已打开文件过多 | 标签横向滚动，不压缩宽度、不折叠成下拉菜单 |
| 激活标签名过长 | 单行截断 + tooltip；宽度上限 220px |
| 树标题过长 | 单行截断 + tooltip，不换行、不缩字 |
| 文档无标题 | 显示「无标题文档」占位，保存时用首个 H1 前 40 字生成文件名，冲突追加序号 |
| 空知识库 | 画布中央引导：选择文件夹 / 新建第一篇；树区显示两行说明，不放大插画 |
| 空文件夹 | 树区就地一行「此文件夹为空」，右侧画布保持上次内容 |

### 5.4 主路径

选择文件夹 → 树渲染 → 点击文档（未打开则新开标签，已打开则激活）→ 画布加载 → 输入（800ms 防抖保存）→ 状态栏「已保存」→ 切换标签 / 关闭标签 / 关窗时 flush。

## 6. 层次与投影

| 层 | z-index | 表面 | 边界 | 说明 |
|---|---|---|---|---|
| 基座 | 0 | `--canvas` | 无 | 窗口底、状态栏 |
| 工作区 | 0 | `--surface` / `--surface-sunken` | 1px `--border`，圆角 14px | 两张卡片；主区加 `--shadow-card` 极轻投影，用来托住卡片边界 |
| 标签行 / 工具栏 | 10 | `--surface-sunken` / `--surface` | 底部 1px | 卡片内固定段，不投影 |
| 大纲抽屉 | 20 | `--surface` | 左侧 1px + `--shadow-overlay` | 从工具栏下缘滑出，覆盖编辑区，不挤压正文 |
| 浮层（菜单、命令面板） | 30 | `--surface` | 1px + `--shadow-overlay` | 允许阴影 |
| 对话框 | 40 | `--surface` | 1px + 更大阴影 | 仅用于不可逆确认 |

规则：
- 只有一个深度的「浮起」——浮层。面板与画布之间不用阴影制造层级。
- 圆角语言四档：6px（行内码、任务方框、关闭按钮）、9px（按钮、树行、标签 chip）、14px（外壳卡片、代码块、大纲抽屉）、18px（命令面板）。胶囊只用于状态徽标。
- 卡片只有两张：左树与主区。主区内的标签行、工具栏、画布是同一张卡片的三段，不再各自套框。
- 禁止：卡片套卡片、为每个区块加容器、装饰性渐变、毛玻璃（除命令面板遮罩的 2px 模糊）。

## 7. 注意事项

| 禁止 / 风险 | 原因 | 可观察的检查 |
|---|---|---|
| 用紫色渐变或大面积强调色 | 与「正文唯一主角」冲突，且是通用 SaaS 皮肤 | 截图转灰度后，强调色区域仍应只占 <5% |
| 把正文塞进卡片 | 双层边框会切断阅读节奏 | 正文列左右应只见画布，不见第二层框 |
| 用 toast 代替保存状态 | 写作中的人不会盯着右下角 | 断开写入权限，状态栏必须持续显示「保存失败」 |
| 为即时渲染改写 md 结构 | 破坏保真承诺，S/M 级事故 | 开关前后复制全文 diff，必须 0 差异 |
| 中文输入法期间重建装饰 | 组合串被打断，出现丢字/跳字 | 用微软拼音连续输入 30 字，光标不跳、标记不闪 |
| 树里只用图标区分文件夹与文档 | 颜色/形状不足以区分时不可识别 | 灰度截图仍能分辨层级与类型 |
| 缩小正文字号换取更多行 | 长文阅读的首要伤害 | 200% 缩放后正文仍可读，不出现横向滚动 |
| 表格在 P0 强行渲染 | 表格 widget 是 Typora 最复杂模块，会拖垮 3 天计划 | P0 验收时应以等宽源码显示，且可正常编辑保存 |
| 图标充当品牌标识 | 混淆产品身份与操作 | 应用图标与窗口标题使用文字 wordmark「md-rust」，不用 emoji 或 Lucide |
| 破坏性操作静默执行 | 不可恢复 | 删除必须写明「移到 .trash」，且可撤销 |
| P0 自绘窗口标题栏 | 自绘要处理拖拽区、最大化、DPI 与系统菜单，3 天内不划算 | 应用内最上一行是标签行，窗口边框由系统提供 |

**未决**：产品对外名称未定（当前用代号 md-rust），wordmark 为临时文字标识，不做 logo 设计；标签系统（`#tag`）是否进 P0 未定，暂不进。

## 8. 响应式行为

### 8.1 断点

| 宽度 | 变化 |
|---|---|
| ≥ 1440px | 双栏完整，正文 720px 居中，工具栏全量 |
| 1080–1439px | 双栏完整；工具栏 1080px 以下隐藏「插入」组 |
| 860–1079px | 左栏可收窄至 200px；工具栏只剩行内格式与右侧开关 |
| < 860px | 左栏收起为抽屉（Ctrl+\ 切换），标签行与编辑区占满 |
| 最小窗口 | 960×600；低于此尺寸禁止继续缩小，避免控件重叠 |

### 8.2 键盘与焦点

| 快捷键 | 行为 |
|---|---|
| Ctrl+P | 命令面板 / 快速打开 |
| Ctrl+W | 关闭当前标签（有未保存时先 flush） |
| Ctrl+Tab | 切换标签；Ctrl+1…8 直达第 N 个 |
| Ctrl+Shift+F | 全文搜索 |
| Ctrl+S | 立即保存 |
| Ctrl+\ | 折叠/展开左栏 |
| Ctrl+Shift+O | 大纲浮层 |
| Ctrl+B / I / K | 加粗 / 斜体 / 链接 |
| F2 | 重命名当前文档 |
| Esc | 关闭浮层，焦点回到触发元素 |

焦点顺序：标签行 → 左栏树 → 工具栏 → 正文 → 大纲抽屉。所有浮层打开时焦点进入，关闭时归还；Tab 不逃出对话框。

### 8.3 触摸与动效

- 本产品为桌面优先，触摸不是主路径；若未来上平板，所有图标按钮需扩到 44×44 命中区（视觉仍 30px）。
- 动效仅两处：侧栏折叠 160ms、面板出现 120ms。`prefers-reduced-motion: reduce` 时全部取消。
- 无循环动画，除未保存转「保存中」时的 1 次脉冲。

### 8.4 状态清单（验收用）

| 状态 | 位置 | 要求 |
|---|---|---|
| 空知识库 | 画布中央 | 两个动作：选择文件夹 / 新建文档；说明一句，不放大图 |
| 无匹配搜索 | 面板列表 | 显示查询词 + 「搜索整个知识库」入口 |
| 加载中 | 画布 | 骨架不超过 200ms 时不出，超过则显示三行灰条 |
| 文件被外部修改 | 画布顶部内联条 | 「磁盘内容已变化」+ 加载磁盘版本 / 保留我的 |
| 保存失败 | 状态栏 + 编辑区顶部内联条 | 原因 + 重试 + 另存为 |
| 文件不存在 | 画布 | 说明 + 从树中移除 / 重新定位 |
| 只读文件 | 状态栏 | 锁标记 + 「只读」，输入直接被拒绝并说明原因 |
